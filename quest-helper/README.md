# Quest Helper

Assistant de quêtes et couche d’optimisation de la suite Atlas.

## Dépendances

Quest Helper 2.0 dépend d’**Atlas Route Guide 1.0**, qui dépend lui-même d’**Atlas Navigator 2.0**. Activer Quest Helper charge donc automatiquement la chaîne complète dans le bon ordre.

## Fonctions

- classe les quêtes par rendement ou par proximité ;
- respecte la quête déjà suivie lorsque ce mode est choisi ;
- synchronise le point de repère du journal ;
- publie automatiquement la quête recommandée comme itinéraire Atlas ;
- recalcule la distance, le temps estimé, la progression et le rendement ;
- passe à la meilleure quête suivante lorsque l’objectif disparaît de la liste active ;
- permet de verrouiller manuellement une quête en la sélectionnant.

## Utilisation

1. Activez **Quest Helper — Guide rentable**.
2. Choisissez **Plus rentable**, **Plus proche** ou **Déjà suivie**.
3. La quête recommandée apparaît sur Atlas et dans Atlas Route Guide.
4. Suivez la flèche jusqu’à l’objectif ; le trajet se met à jour avec la position du joueur.

Quest Helper ne téléporte pas le personnage et ne valide jamais une quête à sa place.
