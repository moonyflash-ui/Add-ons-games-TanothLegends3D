# Chronomètre de Tanoth — Heure & FPS

Affichage léger prévu pour rester lisible sans gêner le combat.

## Fonctions

- heure locale IRL, avec secondes facultatives ;
- heure du monde de Tanoth ;
- FPS réellement mesurés par l’optimiseur du monde 3D ;
- mode compact ;
- position en bas à droite, en bas au centre ou en haut au centre ;
- opacité réglable ;
- couleur des FPS adaptée aux performances.

Le module est aussi une dépendance de **HUD Dark Fantasy 3.0**. Il est donc activé automatiquement avec ce HUD, tout en conservant ses propres réglages.
